Jest framework note

✏️describe() = Тестийн бүлэг, тест бүлэг үүсгэгч
✏️it()/ test() = Нэг тест бичих зориулалттай
✏️expect() =Үр дүн шалгах(Тестийн шалгалт хийх стандарт функц)
✏️toBe(), toEqual(), toThrow() = Төрөл бүрийн шалгалт(expect() дотор хэрэглэгддэг )
✏️beforeEach() = Тестийн өмнө тохиргоо (Бүх тестийн өмнө ажиллуулах тусгай функц)
✏️jest.fn() = Fake function хийх
✏️jest.mock()Model, API mock хийх, Бодит модулийг хуурамчаар солино
